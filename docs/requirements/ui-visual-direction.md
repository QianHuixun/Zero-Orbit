# UI 方向文档：个人网站+博客

## 背景与目标

本文件记录个人网站+博客第一版的视觉与布局方向，用于承接 `personal-site-blog.md` 中的产品需求，并为后续设计与实现提供 UI 基准。

站点视觉方向从“温馨轻松”调整为“黑暗高级、轻科幻、个人知识终端”。首页需要具备强画面冲击力，首屏以宇宙背景和动态知识星图作为核心视觉；首屏之后回归清晰、克制、可检索的博客信息结构。

### UI 目标

- 建立一个有记忆点的个人网站首页，而不是普通博客模板。
- 通过宇宙、星图、轨道、数据节点表达“思想花园”和“个人知识库”。
- 首页首屏允许炫技，但动效应服务于频道探索、内容入口和个人气质表达。
- 文章阅读、频道浏览和检索页面保持稳定、清晰、长期可用。
- 保持高级感，避免廉价霓虹、游戏化界面和科技大屏堆砌。

## 整体视觉基调

### 关键词

- 黑暗高级。
- 轻科幻。
- 个人知识终端。
- 深空宇宙。
- 动态知识星图。
- 克制的信息仪表盘。
- 高冲击首页，低干扰阅读。

### 色彩方向

- 背景使用深石墨、近黑蓝、暗灰或冷黑，不使用纯黑作为唯一底色。
- 主文字使用冷白、浅灰，保证正文阅读对比度。
- 强调色控制在 1-2 个主色，优先考虑电青、幽蓝、微紫或少量酸性绿。
- 高亮色只用于交互状态、星图节点、轨道激活、搜索聚焦和关键状态。
- 避免全站大面积蓝紫霓虹，避免页面被单一色系统治。

### 材质与形态

- 使用细边框、半透明暗面板、微弱辉光和轻量网格建立科技感。
- 圆角保持克制，建议 6px-8px。
- 卡片不应层层嵌套。
- 不使用厚重玻璃拟态，不使用大面积毛玻璃遮挡正文。
- 装饰元素应集中服务于首页首屏和少量交互反馈。

## 首页概念

首页定义为“个人知识宇宙”的入口。

首屏不是普通 Hero，而是一个可交互的深空知识星图。用户进入页面时，应感受到这是一个私人知识数据库、航行日志和思想宇宙的入口。

### 首屏核心构成

- 深空宇宙背景。
- 中心知识核心。
- 四个频道主星体。
- 标签小星点。
- 精选文章轨道节点。
- 站点名、一句话介绍、当前状态。
- 文章入口与搜索入口。

### 深空宇宙背景

背景应为程序化或动态生成的深空视觉，不建议直接使用普通宇宙壁纸。

背景层级建议：

- 远景星点层：细密、低亮度、缓慢漂移。
- 星尘噪声层：增加深度和质感，不能影响文字可读性。
- 淡星云层：少量冷色雾状光带，只做氛围。
- 视差层：鼠标移动或设备方向变化时产生轻微景深感。
- 暗角层：保证文字区域有足够对比。

### 动态知识星图

知识星图是首页首屏的主视觉和核心交互。

星图表达规则：

- 中心知识核心代表站点整体知识库。
- 四个频道作为围绕核心运行的主星体：技术、产品/创造、阅读、生活随笔。
- 标签作为小型星点，分布在对应频道附近。
- 精选文章作为更亮的轨道节点，形成可点击入口。
- 文章、标签、频道之间可以用细线或轨道建立弱连接。

交互规则：

- 鼠标移动时，星图产生轻微视角偏移。
- Hover 频道时，对应主星体、轨道、标签和精选文章高亮。
- Hover 精选文章节点时，展示文章标题、摘要、频道和标签。
- 点击频道节点进入频道页。
- 点击文章节点进入文章页。
- 点击搜索入口打开命令面板式搜索。

### 首屏入场动画

首次进入首页时应有一次短启动动画，建立冲击感。

建议节奏：

1. 暗场或低亮度星域出现。
2. 扫描线或微弱数据脉冲扫过。
3. 中心知识核心点亮。
4. 四个频道星体沿轨道展开。
5. 站点名、介绍和入口按钮进入。

时间建议控制在 1.5-2.5 秒。动画结束后进入低频循环状态，避免持续抢夺注意力。

### 首页首屏文案区

文案区应克制，不和星图争夺视觉焦点。

建议包含：

- 站点名或作者名。
- 一句短介绍，例如：记录技术、创造、阅读与生活的私人知识终端。
- 当前关注，例如：当前关注 AI 工具、产品系统、长期写作。
- 两个主要入口：进入文章、打开搜索。

## 首页下方布局

首屏之后应回到清晰的信息结构，避免整页都处于炫技状态。

### 精选轨道

精选文章区域可以延续星图隐喻，但应以可读文章卡片为主。

- 展示少量精选文章。
- 每篇展示标题、摘要、频道、标签和日期。
- Hover 时可以出现轻微边框辉光或关联轨道提示。
- 不要求每篇文章都有封面图。

### 最新日志

最新文章区域采用时间线或日志列表形式。

- 按发布时间展示最新文章。
- 信息密度略高，便于快速浏览。
- 滚动进入视口时可做轻微激活动画。
- 文案可带一点“日志”语感，但保持克制，不要过度中二。

### 索引区

索引区服务于检索优先的产品目标。

- 展示标签入口。
- 展示归档入口。
- 展示频道入口。
- 可以展示文章总数、标签数、最近更新等轻量数据。

## 文章页 UI

文章页应从首页的强视觉中收回来，优先保证阅读质量。

### 布局

- 正文区域居中，宽度适合长文阅读。
- 桌面端可在侧边放置目录索引。
- 移动端目录应收起或放在文章顶部入口中。
- 文章底部提供前后篇、相关文章和返回频道路径。

### 视觉

- 保持深色背景，但正文容器不应过亮或过花。
- 标题、摘要、频道、标签、日期清晰展示。
- 引用、代码块、注释可以使用轻科幻风格，但不能牺牲可读性。
- 正文段落、行高、链接和列表样式应适合长时间阅读。

## 检索页 UI

检索页应呈现为一个高效的个人知识索引。

### 布局

- 顶部使用命令面板感的搜索输入框。
- 下方提供频道筛选、标签筛选和时间归档。
- 搜索结果以列表为主，展示标题、摘要、频道、标签和日期。
- 无结果状态应清晰，但文案保持克制。

### 交互

- 搜索输入获得焦点时可以出现轻微辉光。
- 输入时实时筛选或快速反馈。
- 支持键盘上下选择搜索结果。
- 点击标签或频道后结果即时收敛。

## 频道页 UI

频道页应像星图中的一个分区视图。

- 顶部展示频道名称、简介、文章数和代表标签。
- 文章列表按时间或精选优先展示。
- 可保留轻微轨道、坐标或节点视觉语言。
- 不做过重动画，避免影响内容浏览。

## 关于页 UI

关于页延续个人知识终端气质，但不做完整简历页。

- 展示简短自我介绍。
- 展示当前关注、最近在读、最近在做。
- 展示联系方式或社交链接。
- 可以使用状态面板式布局，但不应堆叠过多卡片。

## 动效原则

### 应该使用

- 首屏启动动画。
- 星图低频循环。
- 鼠标视差。
- Hover 轻微辉光。
- 搜索命令面板打开与关闭动画。
- 文章列表滚动激活。
- 数字或状态轻微计数动画。

### 应该避免

- 大面积粒子爆炸。
- 彩虹霓虹拖尾。
- 夸张 3D 翻转卡片。
- 过长首屏加载动画。
- 每个模块都发光。
- 影响阅读性能的复杂滚动特效。
- 移动端持续高负载动画。

## 响应式要求

- 桌面端优先呈现完整星图与文案区并列布局。
- 移动端保留宇宙背景和知识核心，但简化星图节点数量。
- 移动端首屏动画应更短、更轻，避免卡顿和遮挡文字。
- 所有按钮、标签、文章标题和搜索结果不得出现文字重叠。
- 正文阅读区域在移动端应优先于装饰与动效。

## 可访问性与性能

- 动画应尊重用户的减少动态效果偏好。
- 深色界面必须保证正文、链接、按钮和标签有足够对比度。
- 首页动画不应阻塞主要内容渲染。
- 如果 3D 或 Canvas 动画加载失败，应显示可用的静态首页内容。
- 移动端应控制粒子数量、阴影和模糊效果。

## 风格边界

### 要做成

- 私人知识宇宙。
- 深色高级博客。
- 有冲击力的首页入口。
- 可检索、可长期维护的内容系统。
- 科幻感服务于个人表达和信息探索。

### 不要做成

- 赛博朋克夜店。
- 科技公司官网。
- 游戏 HUD。
- 数据大屏。
- 纯视觉展示站。
- 牺牲阅读体验的特效页。

## 待确认事项

- 站点名称、作者署名和首页一句话介绍。
- 四个频道是否保留当前命名，还是改成更个人化的星体/舱室命名。
- 首页知识核心更偏恒星、黑洞、星环还是数据中枢。
- 强调色最终选择：电青、幽蓝、微紫、酸性绿中的组合。
- 首页首屏是否需要背景音效或完全静音，默认建议完全静音。
- 是否使用真实 3D 实现，或先用 Canvas 2D/伪 3D 实现。

## 验收标准

- 首页首屏具有明确的宇宙感和动态知识星图，第一眼区别于普通博客模板。
- 用户能从首屏进入文章、搜索和四个频道。
- 星图 hover 和点击行为清晰，不影响文字可读性。
- 首屏动画结束后页面进入稳定低干扰状态。
- 首页下方精选文章、最新日志和索引区可清晰浏览。
- 文章页阅读舒适，正文不被动效和装饰干扰。
- 检索页搜索、筛选和结果浏览高效清晰。
- 移动端可用，动画简化后仍保留黑暗轻科幻气质。
